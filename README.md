# ITSE 1301 | Web Design Tools
### Student Labs, Projects & Learning Resources

Welcome to the **Web Design Tools Projects Repository**, a collection of hands-on learning materials for **ITSE 1301 – Web Design Tools** at Dallas College.

This repository supports students as they develop practical skills in creating, styling, testing, and maintaining modern websites using HTML5, CSS3, and responsive web design techniques.

## 📁 What's in This Repository?

Resources may include:

- **Coding Labs:** Guided exercises reinforcing concepts covered in class.
- **Starter Files:** HTML, CSS, images, and other assets needed to begin assignments.
- **Code Examples:** Demonstrations of web development techniques and best practices.
- **Practice Projects:** Opportunities to apply skills independently.
- **Reference Materials:** Supporting documentation, examples, and troubleshooting resources.

Materials will be added and updated throughout the course.

## 🎯 Learning Objectives

Through these activities, students will practice:

1. Creating well-structured webpages using semantic HTML5.
2. Applying CSS to control typography, colors, spacing, and layouts.
3. Designing responsive websites for mobile, tablet, and desktop screens.
4. Organizing website files and managing project assets.
5. Testing, debugging, and improving webpage functionality and accessibility.
6. Following established web development conventions and best practices.

## 🛠️ Recommended Tools

- **Visual Studio Code** — Code editor
- **Google Chrome or Mozilla Firefox** — Browser testing and developer tools
- **Git and GitHub** — Version control and project resources
- **HTML5 and CSS3** — Primary development technologies

## 🚀 Getting Started

1. Locate the lab or project assigned in Brightspace.
2. Read the accompanying instructions carefully.
3. Download the necessary starter files from this repository.
4. Open the project folder in Visual Studio Code.
5. Complete the required work, testing your webpages in a browser.
6. Submit your completed assignment according to the instructions in Brightspace.

**Tip:** Use GitHub's **Code → Download ZIP** option to download repository files without installing Git.

## 💡 Working with Example Code

Students are encouraged to explore, experiment with, and modify the examples provided here.

Remember:

- Read and understand code before using it.
- Follow the requirements of each assignment.
- Test your work at different browser widths.
- Keep your HTML and CSS organized and readable.
- Review instructor feedback and revise your work accordingly.

**The goal is to understand how and why your code works, not simply to reproduce an example.**
