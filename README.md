## Downloading Starter Files

1. Open the assignment instructions in **Brightspace (eCampus)**.
2. Follow the GitHub link to the corresponding starter files.
3. Select the file you need.
4. Click the **Download raw file** icon near the upper-right corner of the file preview.
5. Save the file to a folder on your computer.
6. Repeat for any additional files required by the assignment.
7. Open the files in **Visual Studio Code** and complete the assignment according to the Brightspace instructions.

### Important Notes

- Download each required file individually.
- Keep the original filenames and file extensions.
- Store related HTML, CSS, and image files in the same folder structure specified by the assignment.
- Do not copy and paste the GitHub webpage itself into your editor.
- Submit completed work using the method specified in Brightspace.

**GitHub provides starter files. Brightspace provides assignment instructions, deadlines, and submission requirements.**
